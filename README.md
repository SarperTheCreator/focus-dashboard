# ⚡ Focus Dashboard

A minimal, dark-themed personal dashboard inspired by the **Olivia** color scheme. Designed for deep focus, quick access to daily shortcuts, and tracking your core focus for the day.

---

## ✨ Features

- 🕒 **Live Digital Clock & Date:** Real-time clock and Turkish date formatting using vanilla JavaScript.
- 🎯 **Daily Focus Tracker:** Clean input field to set your daily intention, automatically saved to `localStorage`.
- 🚀 **Quick Shortcuts:** Instant links to frequently used platforms (GitHub, Monkeytype, YouTube).
- 🎨 **Olivia Aesthetics:** Earthy, desaturated dark tones crafted for minimal eye strain and late-night coding sessions.
- ⚡ **Zero Dependencies:** Pure HTML, CSS, and JS — lightweight and blazingly fast.
